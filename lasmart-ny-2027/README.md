# Lasmart — открытка партнёрам, 2027

Квадрат **180 × 180 мм**, 2 полосы. 2027 — год Козы.

## Задумка

Геометрическая мозаика, как у золотого коня на зелёном поле: крупный силуэт, хвоя, игрушки, конфетти. Только вместо коня — **коза**.

Палитра референса сохранена (глубокий зелёный + фольговое золото + кремовый). В мозаику добавлены три корпоративных штриха Lasmart:

- циан — треугольник на плече;
- маджента — ромбы на боку;
- лайм — схема платы и полоска на игрушке.

IT читается не отдельной картинкой, а узором: микросхема, снежинка-граф, узлы на плате.

## Печать

- картон 300–350 г/м², тёплый белый или тёмно-зелёный, без мелования;
- лицевая + оборот;
- при печати в край добавить 3 мм bleed.
