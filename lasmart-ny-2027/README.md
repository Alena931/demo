# Lasmart — открытка партнёрам, 2027

Формат: **148 × 210 мм** (A5, портрет), 2 полосы.

## Задумка

Композиция как у классической новогодней открытки: игрушки висят на нитях сверху, слева воздух, внизу поздравление. Только вместо шаров и подарков — IT-мотивы:

- шар с графом-снежинкой (сеть данных);
- шар-датчик и шар-чип;
- «ёлки» из шевронов — как дерево иерархии;
- модули-релизы с лентой;
- кластер из трёх узлов.

Цвета: **синий и голубой** из логотипа. Фон не пустой: едва заметная сетка дашборда, дуги радара, тонкие «потоки» данных и микроузлы.

## Печать

- картон 300–350 г/м², тёплый белый, без мелования;
- лицевая + оборот;
- при печати в край добавить 3 мм bleed.
