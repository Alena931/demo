# Lasmart — открытка партнёрам, 2027

Квадрат **180 × 180 мм**. Сейчас собираем **лицевую**.

2027 — год Козы. Геометрическая мозаика с референса (золотой конь → коза).

На теле: платы и дорожки, чип, граф, снежинка-сеть, циан / маджента / лайм / жёлтый из логотипа. На игрушках: шар-диаграмма и шар-чип.

## Фон, три более светлых оттенка

Исходное поле было почти ночным (`#043E2F`). Варианты лица — в `variants/`:

| | имя | hex | характер |
|---|---|---|---|
| A | Хвоя | `#1B6A4A` | всё ещё глубокий лес, на ступень светлее |
| B | Малахит | `#228A58` | средний, золото читается как фольга |
| C | Шалфей | `#3AA06C` | самый открытый, дневной зелёный |

Печать: картон 300–350 г/м², без мелования, bleed 3 мм.
