# Lasmart — открытка партнёрам, 2027

A5 148 × 210 мм, две стороны.

Новая концепция в `pixel/`: пиксельная ёлка с ювелирными IT-игрушками.
Задний план объёмный — пиксельный лес, серверные стойки, плата в снегу.
Снег — пиксельные квадраты и снежинки, без нулей и единиц.

## Пиксельные варианты фона

Navy-семейство (тот же цвет, светлее):

- `pixel/lasmart-2027-pixel-a-navy-mid` — средний navy
- `pixel/lasmart-2027-pixel-f-navy-light` — светлый navy, серверы на горизонте
- `pixel/lasmart-2027-pixel-g-navy-mist` — дымка
- `pixel/lasmart-2027-pixel-b-navy-ice` — самый светлый, лёд

Другие новогодние:

- `pixel/lasmart-2027-pixel-e-twilight` — циан / сумерки
- `pixel/lasmart-2027-pixel-c-forest` — хвоя
- `pixel/lasmart-2027-pixel-d-burgundy` — бордо

Сетка: `pixel/lasmart-2027-pixel-compare.png`.

Выбранная лицевая — сумерки / циан. Оборот — белый фон, тёмно-синий текст, лёгкие силуэты платы.

Печатный комплект в `pixel/print/`:

- `lasmart-2027-a5-148x210.pdf` — лицевая A5
- `lasmart-2027-back-148x210.pdf` — оборот A5
- `lasmart-2027-otkrytka-a5.pdf` — лицевая + оборот
- `lasmart-2027-a5-bleed-3mm.pdf` / `lasmart-2027-back-bleed-3mm.pdf` — вылет 3 мм
- `lasmart-2027-a5-cropmarks.pdf` — метки реза, лицевая
- `lasmart-2027-a5-300dpi.tif` / `.jpg` / `.png` — растр лицевой, 300 dpi

## Предыдущие концепции

Висящая композиция: `hanging/`. Квадратная коза и зелёные фоны: `variants/`.

Печать: картон 300–350 г/м², без мелования, bleed 3 мм.
