# Lasmart — открытка партнёрам, 2027

Сейчас в работе **лицевая**, A5 148 × 210 мм.

Висящая композиция: игрушки как IT-мотивы, поздравление внутри сцены. Палитра логотипа целиком — navy, циан, лайм, маджента, жёлтый. Фон: сетка дашборда, граф-созвездие, потоки данных.

## Файлы

- `lasmart-2027-front.pdf` — лицевая в печать
- `lasmart-2027-front-print.svg` — вектор, текст в кривых
- `lasmart-2027-front.svg` — редактируемый вектор
- `hanging/generate_card.py` — сборка

Печать: картон 300–350 г/м², без мелования, bleed 3 мм.

Квадратная коза и три зелёных фона лежат в `variants/`.
