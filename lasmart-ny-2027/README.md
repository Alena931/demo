# Lasmart — открытка партнёрам, 2027

Формат: **210 × 148 мм** (A5 landscape), 2 полосы.

## Задумка

Открытка не собирает новогодние картинки. Она повторяет грамматику логотипа Lasmart: зелёный модуль слева, синее поле, три цветные плитки сверху. На месте названия компании — год. Для тех, кто знает логотип, это сразу читается. Для остальных — спокойный геометрический жест.

Фраза на лицевой: «всё важное — на виду» — про ясность данных, не про ёлку.

Тренды 2026–2027, которые здесь использованы:
- крупная типографика как главный объект;
- смелые геометрические модули вместо иллюстрации;
- неожиданная для НГ палитра (цвет логотипа, не красно-зелёный);
- тёплая «бумажная» плашка, много воздуха.

## Печать

- бумага: непромелованый картон 300–350 г/м², тёплый белый;
- лицевая + оборот, без сгиба (открытка-планшет на стол);
- по желанию: выборочный УФ или тиснение на трёх плитках;
- вылеты под обрез не заложены — если нужна печать в край, добавить 3 мм bleed.
