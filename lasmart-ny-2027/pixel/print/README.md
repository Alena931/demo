# Lasmart 2027 — печатные файлы

Формат: A5, 148 × 210 мм, две стороны.
Разрешение: 300 dpi. Цветовое пространство: RGB.

## Что отдавать в типографию

- `lasmart-2027-otkrytka-a5.pdf` — лицевая + оборот, без вылетов.
- `lasmart-2027-a5-148x210.pdf` — только лицевая.
- `lasmart-2027-back-148x210.pdf` — только оборот.
- `lasmart-2027-a5-bleed-3mm.pdf` / `lasmart-2027-back-bleed-3mm.pdf` — вылет 3 мм.
- `lasmart-2027-a5-cropmarks.pdf` — лицевая с метками реза.
- `lasmart-2027-a5-300dpi.tif` / `.jpg` / `.png` — растр лицевой.

Рекомендация: картон 300–350 г/м², без мелования. Вылет 3 мм со всех сторон.
